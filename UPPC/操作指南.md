# UPPC 上位机操作指南

## 目录结构
```
R2/UPPC/
├── src/                          ← 6 个 ROS2 包（源码，--symlink-install 改即生效）
├── scripts/
│   ├── uppc_start.sh             ← systemd 开机自启脚本
│   ├── web_control.py            ← Web 遥控面板
│   ├── control.html              ← 键盘操控页面
│   ├── editor.html               ← 键位编辑页面
│   └── keymap.json               ← 键位映射配置
└── build/ install/ log/          ← 编译产物（不要提交 git）
```

## 编译

首次 clone 或 msg/srv 接口有改动时需要编译，日常改 Python 源码**不需要重编**。

```bash
cd ~/main_R2/main_R2/R2/UPPC
colcon build --symlink-install --cmake-force-configure \
  --cmake-args -DPython3_EXECUTABLE=/usr/bin/python3.10
```

## 启动 / 停止 上位机

### 一键启停（systemd 服务，开机自启）
```bash
sudo systemctl start uppc        # 启动
sudo systemctl stop uppc         # 停止
sudo systemctl restart uppc      # 重启（改源码后执行）
sudo systemctl status uppc       # 查看状态
sudo systemctl enable uppc       # 设为开机自启
sudo systemctl disable uppc      # 取消开机自启

journalctl -u uppc -f            # 实时日志
journalctl -u uppc -n 50         # 最近 50 行日志
```

### 启动的节点列表
```
livox_lidar_publisher   ← MID360 雷达驱动（无硬件时 bind 失败，不影响其他节点）
fastlivo_mapping        ← 激光 SLAM 里程计
lidar_odom_relay        ← 里程计坐标转发（/aft_mapped_to_init → /odometry）
serial_bridge           ← 串口桥（上行里程计/KFS + 下行摄像头指令 + PC遥控接收）
state_machine           ← 主流程状态机（INIT → IDLE → TRACKING → ARRIVED）
```

## 单独启动节点（调试用）

先 source 环境：
```bash
source /opt/ros/humble/setup.bash
source ~/lidar/ws_livox/install/setup.bash
source ~/桌面/kfs_ws/install/setup.bash
source ~/main_R2/main_R2/R2/UPPC/install/setup.bash
```

各节点：
```bash
# 串口桥（核心节点：里程计上行 + PC遥控接收 + 下行协议解析）
ros2 run vision_grasp_serial serial_bridge_node --ros-args -p port:=/dev/ttyUSB_serial

# 里程计转发
ros2 run vision_grasp_lidar odom_relay_node

# 状态机
ros2 run vision_grasp_state_machine state_machine_node

# 摄像头检测
ros2 run vision_grasp_camera detector_node
```

## Web 遥控面板（GUI）

```bash

python3.10 ~/main_R2/main_R2/R2/UPPC/scripts/web_control.py &

# 另一台电脑（同一局域网）浏览器打开：
#   http://192.168.31.135:17890          → 键盘操控
#   http://192.168.31.135:17890/editor    → 键位编辑
```

无需安装任何软件，浏览器直接打开就行。系统不限（Windows / macOS / Linux / 平板）。

## 查看运行状态

```bash
# 查看所有 ROS2 节点
ros2 node list

# 查看所有话题
ros2 topic list

# 监听某个话题（调试用）
ros2 topic echo /chassis_cmd
ros2 topic echo /odometry
ros2 topic echo /camera_command
```

## 查看 / 修改键位

```bash
# 命令行直接编辑
vim ~/main_R2/main_R2/R2/UPPC/scripts/keymap.json

# 或浏览器打开键位编辑页面
# http://192.168.31.135:17890/editor
```

## 杀掉进程

```bash
# 杀 Web 面板
kill $(lsof -t -i:17890)

# 杀整个上位机服务
sudo systemctl stop uppc

# 杀残留 ROS2 节点
pkill -f serial_bridge_node
pkill -f odom_relay_node
pkill -f state_machine_node
pkill -f detector_node

# 查看是否还有残留
ps aux | grep -E "vision_grasp|web_control"
```

## 查看运行日志

```bash
# 上位机 systemd 服务日志
journalctl -u uppc -f

# ROS2 节点日志（在 ~/.ros/log/ 下）
ls -lt ~/.ros/log/ | head -5
```

## 维护

### 拉最新代码并部署
```bash
cd ~/main_R2/main_R2/R2
git pull
cd UPPC
# Python 源码改动直接生效，无需重编
# 如果有 msg/srv 接口改动，执行：
colcon build --symlink-install --cmake-force-configure \
  --cmake-args -DPython3_EXECUTABLE=/usr/bin/python3.10
sudo systemctl restart uppc
```

### 下位机（STM32）改动
```bash
# 1. 修改 C 代码
vim ~/main_R2/main_R2/R2/RC26_H7_R2/.../xxx.c

# 2. Keil MDK 编译 → 生成 .bin/.hex

# 3. ST-Link / 串口烧录到 STM32 开发板
```

### 开机自启管理
```bash
# 设为开机自启
sudo systemctl enable uppc

# 取消开机自启
sudo systemctl disable uppc

# 查看是否开机自启
sudo systemctl is-enabled uppc
```
