● 速度模式（模式0/1）

模式0 — below 速度控制（默认）
遥控: below_cmd = (CH2 - 992) × 200
仅遥控模式可用，全自动模式无效
模式1 — above 速度控制
遥控: above_cmd = (992 - CH2) × 200
仅遥控模式可用，方向与 below 相反

● 位置模式（模式2/3） ★ NEW

模式2 — below 位置控制 | above=0 | 反馈: kfs_below.round_cnt | 输出: +raw×200 | 遥控+全自动 ★
模式3 — above 位置控制 | below=0 | 反馈: kfs_above.round_cnt | 输出: -raw×200 | 遥控+全自动 ★
★ 切入位置模式时
base_rounds = 当前电机.round_cnt
target_pos = pos0
积分/微分清零
CH2 边沿（位置模式下）
CH2 ≥1500 → pos+1（饱和 pos3）
CH2 ≤500 → pos-1（饱和 pos0）
★ 目标圈数 (pos_rounds数组)
target_rounds = base_rounds + pos_rounds[pos_idx]

⚙ 位置环 PID（above/below 共用） ★ NEW

error = target_rounds - round_cnt
integral += error   [clamp: ±pos_i_limit]
derivative = error - last_error
output = P×error + I×integral + D×derivative
[clamp: ±max_speed]
量纲转换 + 方向适配
below: speed_cmd = output × 200
above: speed_cmd = -output × 200
