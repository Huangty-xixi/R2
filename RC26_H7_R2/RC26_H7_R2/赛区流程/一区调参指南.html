一区调参指南

zone1 全接管 · 累计消抖/失料 · 碰壁清 mask · odom 丢帧兜底

状态3 子阶段: PE9=1瞬间 VW=0 → debounce(T1) → close(T2) → loss(T3) → 直接跳状态5
消抖: 累计 PE9=1 须 >= T1_thr 才算有料。VW 死锁 0 等满 T1
失料: 累计 PE9=0 >= T3_thr 才判失。舵机有充分时间抬
mask 消抖通过才置位，假信号不记仇。碰边界反向 mask 全清

调试变量 (g_app_zone1_dbg)

变量看什么
state主状态 3=扫 5=转180 6=等R1 7=卸 8=完
grab_sub_state子阶段 0=扫 1=消抖 2=合 3=失
grab_phase_start_ms当前阶段起始 tick。now_ms-它=已过
anchor_triggered_maskbit0~5 锚点触发标记
center_y_m物料 Y 坐标 + 有效性 flag

时序参数 (g_app_zone1_cfg)

参数默认管什么
clamp_debounce_ms20msT1 消抖窗口
clamp_debounce_present_ms10msT1 内 PE9=1 累计 >=此值才有料
clamp_close_dwell_ms200msT2 闭合等待。满后抬舵机
clamp_loss_check_ms500msT3 失料检测窗口(等舵机抬)
clamp_loss_absent_ms10msT3 内 PE9=0 累计 >=此值才失料
anchor_trigger_radius_m0.06m锚点触发半径

锚点/横扫

参数默认管什么
sweep_anchor_y_m[6]0.45~1.426 锚点 Y 坐标
sweep_anchor_slow_radius_m0.10m锚点减速半径
sweep_vw_min_scale0.3锚点最低速 = 全速 × 此值
shift_right_slow_cmd45°/s横扫全速

调试流程

1. debug_skip_to_wait_r1=1 → 启动 → 验证 6/7/8 正常
2. debug_skip_to_wait_r1=0 → 正常跑 → 看 grab_sub_state:
  0: PE9 没响 / 锚点不对 → 查传感器/半径
  1: 消抖没过 → T1 太小 / 累计阈值太高
  2: 闭合失败 → 查气路 / T2 太小
  3: 频繁失料 → T3 太小 / 累计失料阈值太低
3. 看 anchor_triggered_mask 确认锚点触发
4. grab_phase_start_ms vs now_ms → 精确到 ms 的相位时间
