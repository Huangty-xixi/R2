## E 组：取消与边界

### E1. CH5×5（mod0）取消

- [ ] CH7 min → CH5×5（s_count=5, mod5=0）
- [ ] 等 2 秒 → 蜂鸣器连续长响
- [ ] CH7 max → 蜂鸣停，回到 IDLE，正常比赛等待

### E2. CH5 慢拨超过 2 秒

- [ ] CH7 min → CH5×1 → 计数=1
- [ ] 等 3 秒（超过 2 秒窗口）→ 蜂鸣进入 FEEDBACK，1 声/秒
- [ ] 再拨 CH5 → 不响应（FEEDBACK 状态忽略 CH5）
- [ ] CH7 max → mod5=1 → 取消 retry → 正常比赛启动

### E3. FEEDBACK 5 秒超时

- [ ] CH7 min → CH5×2 → 等 2 秒 → 蜂鸣 2 声/秒
- [ ] 不操作，等 5 秒 → 蜂鸣器自己停，s_state=IDLE

### E4. 正常比赛误拨 CH5

- [ ] 比赛运行，CH7 在 max
- [ ] CH5 随便拨 → 蜂鸣器不响，retry 无响应

### E5. 二区 1 秒等待期间 CH5 无效

- [ ] CH7 min → CH5×2 → CH7 max → 进入 EXECUTING
- [ ] 1 秒等待期间拨 CH5 → 不响应（门控锁死）
- [ ] 1 秒后 zone2 正常启动
