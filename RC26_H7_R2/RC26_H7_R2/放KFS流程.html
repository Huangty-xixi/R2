↺ 逆时针
弹仓 = three_kfs 电机
4个槽位 P1~P4，每个槽一颗弹丸

↺ 逆时针递减:
P4 → P3 → P2 → P1 → 空

每发子弹对应一个吸盘:
P3 → sucker4
P2 → sucker3
P1 → sucker2
P4 → 无（最外侧，不直接吸）

每轮一发，放完为止
three_kfs_position P4->P3->P2->P1
round=0: idle rotate once; round=1: pre-rotated by wait_above_retract, idle skip
pre_position -> default(stop,busy=0); next trigger -> idle again
▶ 吸盘 sucker 关断逻辑
放KFS = 释放弹丸，所以 sucker_state = 0U（断开真空，让弹丸掉落）
three_kfs 当前位置对应吸盘操作含义
P4—fallback（无操作）P4位无吸盘，跳过
P3sucker4= 0U → GPIOE.1 RESET吸盘4释放
P2sucker3= 0U → GPIOC.12 RESET吸盘3释放
P1sucker2= 0U → GPIOC.11 RESET吸盘2释放
注意：取KFS 用 = 1U（吸住），放KFS 用 = 0U（释放），方向相反。 对比代码 Process_GetKFS() 中 suckerX_state = 1U

参数值说明
