▶ 调用方 (Zone3)
// app_zone3.c - app_zone3_run_put_kfs()
static void app_zone3_run_put_kfs(now_ms, done_state)
{
   Process_PutKFS(); // 每帧推进
   if (AppZone3_PutKFS_IsBusy() != 0) {
     // 还在放KFS中，检查超时
     if (timeout) → failed;
     return;
   }
   // 放完：地面→返回P1 / R1上→继续等待指令
   begin_nav(P1) // 或 enter_state(on_r1_wait_cmd)
}
每弹一发：Zone3 每次收到放KFS指令只调一次 Process_PutKFS。多弹时需 R1 重复发指令逐发射出。 每发之间弹仓自动预转，下次调用走快速路径(500ms)。
