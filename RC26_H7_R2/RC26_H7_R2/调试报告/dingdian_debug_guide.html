定点导航调试指南

nav_goto_dingdian_debug.c | Watch 窗口控制 | g_nav_goto_dingdian_debug

前置条件
条件说明
控制模式遥控器 CH8 中位 → full_auto_control
流程空闲flow_mode == flow_none 且 app_flow_mode == app_flow_none
ODOM 有效rc_odom_is_valid() == 1
编译开关ODOM_NAV_GOTO_DINGDIAN_DEBUG = 1（app_init.h 默认已开）
三种模式
abc效果
100正方形 A：(x+1,y)→(x+1,y+1)→(x,y+1)→回原点
010正方形 B：(x+1,y+1)→(x,y+1)→(x+1,y)→回原点
101正方形 A + 并发转向 NEW
011正方形 B + 并发转向 NEW
11-取消/中止（立即复位）
NEW 并发转向模式 — c=1 时每段导航+转向同时进行
第1段
转向 场左 LEFT
+ 导航 (dx, 0)
→
第2段
转向 场后 BACK
+ 导航 (dx, dy)
→
第3段
转向 场右 RIGHT
+ 导航 (0, dy)
→
第4段
转向 场前 FRONT
+ 回原点 (0, 0)
并发逻辑：每段在 odom_nav_goto_set_target() 的同时调 YawHeadingCtrl_RunFieldDir()， 导航和转向各自异步执行，不互相等待。走完4段自动清零 a=b=c=0。
操作步骤
步骤操作
1Keil 进 Debug，打开 Watch 窗口，添加 g_nav_goto_dingdian_debug
2确保机器人在平地、ODOM 定位正常、全自动模式空闲
3Watch 窗口设 a=1, c=1（正方形A+并发转向）
4机器人自动以当前位置为锚点，走正方形4段
5走完自动清零；中途设 a=1,b=1 可强制中止
步长调节：修改宏 NAV_GOTO_DINGDIAN_STEP_M（默认 1.0m），或 Keil 里 -D 覆盖。
俯视图（正方形 A + 并发转向）
