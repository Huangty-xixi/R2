💡 vy vs vw 参数为什么不一样？

麦轮前后运动是四个轮子同向转，摩擦小；左右横移是对角轮配对，滚子横向力分量要克服大得多的摩擦。所以 vw 的 P/I/Limit 都是 vy 的 5~10 倍。

🔵 第四层 · 航向保持（遥控平移用）🆕 chassis_heading_hold 串级双环改造

文件：chassis_heading_hold.c:10-25  |  结构体：g_heading_hold

遥控模式下，平移时锁定当前航向角。就是用户说的 "陀螺仪"。

🆕 控制架构变更：单环 → 串级双环

❌ 旧架构（单环 PD+I）

角度误差
↓ kp·err + ki·∫err + kd·(-gyro)
三个项混在一起 → Vx 输出
参数: kp=2.6, ki=0.15, kd=0.7
kd 手工拼角速度阻尼，不是真正的内环

✅ 新架构（串级双环）

角度误差
↓ kp_outer · err → clamp(max_rate_dps)
目标角速度 (deg/s)
↓ rate_err = target − gyro_lpf
内环 PI: kp_inner·rate_err + ki_inner·∫rate_err
↓ clamp(out_limit)
Vx 输出
参数: kp_outer=3.7, kp_inner=0.7, ki_inner=0.04
内外环解耦，抗扰动带宽提升 3-5 倍

🧠 核心算法变更：ChassisHeadingHold_Update

chassis_heading_hold.c:543 — 旧 10 行 → 新 15 行

❌ 旧（单环）

err = wrap_deg_180(ref - yaw);

yaw_rate = g_sensor_task_data.imu.gyr_z_dps;
hh->yaw_rate_lpf = α·rate + (1-α)·lpf;

hh->i_term += hh->ki * err * dt;
hh->i_term = clampf(i_term, -i_limit, i_limit);

d_term = hh->kd * (-hh->yaw_rate_lpf);

out = -(hh->kp * err + hh->i_term + d_term);
out = clampf(out, -out_limit, out_limit);

✅ 新（串级双环）

err = wrap_deg_180(ref - yaw);

yaw_rate = g_sensor_task_data.imu.gyr_z_dps;
hh->yaw_rate_lpf = α·rate + (1-α)·lpf;

// ====== 外环：角度→目标角速度 ======
target_rate = hh->kp_outer * err;
target_rate = clampf(target_rate, -max_rate_dps, max_rate_dps);

// ====== 内环：角速度→Vx输出 ======
rate_err = target_rate - hh->yaw_rate_lpf;
hh->rate_i_term += hh->ki_inner * rate_err * dt;
hh->rate_i_term = clampf(rate_i_term, -i_inner_limit, i_inner_limit);

out = hh->kp_inner * rate_err + hh->rate_i_term;
out = clampf(out, -out_limit, out_limit);
out = -out;

⚠️ 关掉这个会发生什么？

当 g_heading_hold.enable = 0（关陀螺仪）时：
→ 平移指令直接进入麦轮运动学分解
→ 四轮 PID 开环驱动（无 yaw 反馈修正）
→ 任何左右力矩不对称（Kd 不一致/重心偏/滚子滑移）都会造成 yaw 漂移
→ 就是用户描述的现象！

⚡ 双环 vs 单环：扰动响应对比

场景：急加速产生 20°/s 的瞬态偏航角速度

时间❌ 旧单环行为✅ 新双环行为
T=0ms 角速度 20°/s，角度还是 0° → P=0, I=0
只有 kd×(−gyro)=0.7×(−20)=−14 → 偏弱		 角速度 20°/s → 内环 rate_err=0−20=−20
→ kp_inner×(−20)=0.7×(−20)=−14，马上全力抵抗！
T=50ms 角度偏 1° → P=2.6×(−1)=−2.6
总输出 −16.6，还在"等角度偏"		 角度偏 0.1° → 外环 target_rate=−0.37
内环 rate_err=−0.37−18=−18.37 → 持续压制
T=100ms 角度偏 2° → P=−5.2，总输出 −19.2
终于跟上来了，但已经偏了 2°		 角度偏 不到 1°，角速度已被压制到 10°/s
内环 I 开始累积 → 稳态误差趋零
T=300ms 角速度归零，角度偏了约 5°
靠 I 慢慢拉回来（还要再等几百ms）		 角度已回到锁定值 ±1°
内环 I 自动补偿残余力矩 → 稳态锁定

双环抗瞬态扰动的带宽约是单环的 3-5 倍。内环在角速度刚出现时就压制，不需要等角度误差积累。

🔧 调参指南（按顺序）

#调什么怎么操作判据
1 kp_inner 遥控给一个小旋转再回中 底盘快速停住不来回摆。太小→软/停不住，太大→震荡
2 ki_inner 停住后观察有无残余慢速漂移 有漂移→加大，无漂移→保持小值（0.02~0.08）
3 kp_outer 平移时故意推底盘使其偏 10°，看回正速度 太小→回得慢（软），太大→过冲。建议 2.5~5.0
4 max_rate_dps 观察大偏角时的回正角速度 建议 30~50，太快→底盘抖，太慢→回正慢
5 yaw_rate_lpf_alpha 看角速度波形噪声 噪声大→减小（更平滑），响应慢→增大（0.03~0.10）

⚠️ 发现 Kd 不对称！

左侧两轮 Kd=0.25，右侧两轮 Kd=0.15，差 67%。
位置式 PID 在阶跃加速时 D 项 = kd × Δerror → 左侧瞬态出力比右侧大 67% → 产生净偏航力矩。
这是遥控+关陀螺时 yaw 漂移的 代码层主因。
