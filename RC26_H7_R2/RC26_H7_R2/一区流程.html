⏱ 状态机详细时序

0
idle — 等待启动
CH7 上升沿触发 或 app_flow_start_match() 自动启动。
AppZone1_Start(): 先发起偏航 90° 命令，再设置导航目标 → 进入 ①
1
nav_turn_open — 导航到开局点 + 偏航 90°
app_zone1_flow_nav_start_xy() 设导航目标（容差 0.05m）+ YawHeadingCtrl_RunFieldDir(左/右 90°)
目标坐标按模式/方色区分：
  技能赛蓝方: APP_ZONE1_OPEN_TARGET_SKILL_BLUE (0.50, 0.96)
  竞技赛/红方: APP_ZONE1_OPEN_TARGET_SHARED (0.61, 0.39)
nav leg 跟踪: s_nav_leg_running + s_nav_leg_session 防重入
完成条件: app_zone1_flow_nav_leg_done() (ARRIVED 或 DISARMED+已到位 或 TIMEOUT) + ParallelLegSettled
超时/失败: action_timeout_ms → abort (DISARMED/ODOM_READ/BAD_CONFIG 也 abort)
2
reverse_slow_to_limit — 倒车到限位
直接写底盘 vy=-15，倒车后退。
限位检测: ≥3轮 转速<10RPM 且 命令>2.0，持续 180ms → 判定停转
超时 6000ms → 仍然继续（FLOW_THROUGH 模式）
或 action_timeout_ms → abort
3
shift_right_monitor — 横扫监测
VW=40(方向依红蓝方) + VY=-8(下压), 持续横扫
每帧读 odom_center_offset_latest_center() 获取检测物体的中心 Y
Y 分区(滞回): below / lo_band / mid / hi_band / above
接近边界或锚点时减速（6个锚点间距0.2m，最低倍率 0.6）
低边界翻转 (lo_flip): 新增预锁机制 — 必须先进入 lo_band/below 才能 arm，arm 后才能触发 lo 边界翻转
  grab_sweep_lo_flip_armed: 离开 lo 区域时置 1，重新进入时清零
  app_zone1_flow_grab_try_flip_lo(): armed=0 时不翻转；done 后不再翻转
center_y < y_lo → 进入 pull_back 阶段，越界后回到 sweep
夹爪 latch: clamp_head 从 idle→closing → 进入 ④
自动抓取: AppZone1_ShouldAllowAutoGrab() 仅在此状态下返回 true
超时 → 若 FLOW_THROUGH: 继续进入 ④ 碰运气
4
shift_right_clamp_wait — 夹爪等待
等 ClampHeadCtrl: dock_ok 返回成功，或 upright_hold 持续 2000ms
重试机制: 夹爪回 idle、未到限位、无物体(IsObjectPresentRaw()==0)、电机空闲 → 消抖 200ms 后回 ③，最多 8 次
  （改用 ClampHeadCtrl_IsObjectPresentRaw() 替代 PE9 absent_filt，更直接）
超时 clamp_timeout_ms(30s) → FLOW_THROUGH 则继续
5
advance_turn180 — 调头
YawHeadingCtrl_PostCommand(turn_180) 调头
同时底盘 vy=10 前进
YawHeadingCtrl busy? → 每帧检查。完成 →:
— 技能赛 skill_lap=0: skill_lap=1, 重置夹爪, 回到 ③ (第二圈)
— 其他: 直接进入 ⑥ (wait_r1，不再有前进限位步骤)
超时 action_timeout_ms → abort
6
wait_r1_release — 等 R1 释放
每帧 R1Link_TakeSig() 轮询 R1 释放信号
底盘锁死: 此状态内 AppZone1_ChassisLockHoldActive() 返回 true，供上层锁定底盘
FLOW_THROUGH 模式下超时 20s 自动退出
收到释放后:
— 技能赛 skill_lap=0 (首圈): skill_lap=1, 重置夹爪, 回到 ⑤
— 技能赛 skill_lap=1 (次圈) / 非技能: → done
7
done
disarm 导航, 清除 override, active=0
Motion_Task 检测到 done → 切换到 app_flow_zone2
8
abort
disarm 导航(含 app_zone1_flow_nav_abort()), 清除 override, active=0, failed=1

🧭 导航与偏航并行

机制实现
导航 legapp_zone1_flow_nav_start_xy(x,y) — 设容差 0.05m, 清理旧 leg, 设目标, 跟踪 session_id + s_nav_leg_running
偏航YawHeadingCtrl_RunFieldDir() (90°) 或 YawHeadingCtrl_PostCommand(turn_180)
到达判定app_zone1_flow_nav_leg_done(): ARRIVED / DISARMED+已到位(距离<容差) / TIMEOUT → 结束 leg
再叠加 YawHeadingCtrl_ParallelLegSettled() (偏航角速度稳定)
里程计保护app_zone1_flow_nav_odom_trustworthy(): 里程计数据年龄 > 500ms → abort
nav leg 防重静态变量 s_nav_leg_running / s_nav_leg_session 追踪当前激活的导航段，peek 时比对 session_id
abort 清理app_zone1_flow_nav_abort(): disarm + 清零 leg_running/session

Y 分区滞回翻转逻辑

边界翻转条件预锁
hi 翻转 (上边界) center_y > y_hi → 翻转扫描方向，hi_flip_done=1 无（直接触发）
lo 翻转 (下边界) center_y < y_lo → 先 try_flip_lo，需 armed=1 才翻转
armed 在离开 lo 区域(center_y > lo_exit) 时置 1		 有 — grab_sweep_lo_flip_armed: 必须先从 mid 进入 lo_band/below 才能 arm
