⏱ 状态机详细时序

0
idle — 等待启动
CH7 上升沿触发 或 app_flow_start_match() 自动启动。
AppZone1_Start() 设置导航目标 → 进入 ①
1
nav_turn90_to_open — 导航 + 偏航
odom_nav_goto 到开局点 (蓝:0.58,0.55 / 红:0,0)
并行 YawHeadingCtrl_RunFieldDir(左/右 90°)
完成条件: 导航 ARRIVED + ParallelLegSettled
超时(action_timeout_ms) → abort
2
reverse_slow_to_limit — 倒车到限位
直接写底盘 vy=-15，倒车后退。
限位检测: ≥3轮 转速<10RPM 且 命令>2.0，持续 180ms → 判定停转
超时 6000ms → 仍然继续（FLOW_THROUGH 模式）
或 action_timeout_ms → abort
3
shift_right_monitor — 横扫监测
VW=40(方向依红蓝方) + VY=-8(下压), 持续横扫
每帧读 odom_center_offset_latest_center() 获取检测物体的中心 Y
Y 分区(滞回): below / lo_band / mid / hi_band / above
接近边界或锚点时减速（6个锚点间距0.2m）
夹爪 latch: clamp_head 从 idle→closing → 进入 ④
超时 → 若 FLOW_THROUGH: 继续进入 ④ 碰运气
4
shift_right_clamp_wait — 夹爪等待
等 ClampHeadCtrl: dock_ok 返回成功，或 upright_hold 持续 2000ms
重试机制: 夹爪关闭失败(回idle + 无物体 + 未到限位) → 重新初始化夹爪，回到 ③，最多 8 次
超时 clamp_timeout_ms(30s) → FLOW_THROUGH 则继续
5
advance_turn180 — 调头
YawHeadingCtrl_PostCommand(turn_180) 调头
同时底盘 vy=10 前进
YawHeadingCtrl busy? → 每帧检查。完成 →:
— 技能赛 skill_lap=0: skill_lap=1, 重置夹爪, 回到 ③ (第二圈)
— 其他: 进入 ⑥
超时 action_timeout_ms → abort
6
forward_slow_to_limit — 前进到限位
直接写底盘 vy=15，前进。
限位检测（同 ②）: ≥3轮停转 ≥180ms → 进入 ⑦
超时 6000ms → FLOW_THROUGH 继续
7
wait_r1_release — 等 R1 释放
每帧 R1Link_TakeSig() 轮询 R1 释放信号
FLOW_THROUGH 模式下超时 20s 自动退出
收到释放后:
— 技能赛 skill_lap=0 (首圈): skill_lap=1, 重置夹爪, 回到 ⑤
— 技能赛 skill_lap=1 (次圈) / 非技能: → done
8
done / abort
done: disarm 导航, 清除 override, active=0
abort: 同上, failed=1
Motion_Task 检测到 done → 切换到 app_flow_zone2

🧭 导航与偏航并行

机制实现
导航odom_nav_goto_set_target() — 由 odom_nav_goto_service_tick() 每帧驱动（Zone1 只设目标、peek 结果）
偏航YawHeadingCtrl_RunFieldDir() (90°) 或 YawHeadingCtrl_PostCommand(turn_180)
到达判定导航 ARRIVED + YawHeadingCtrl_ParallelLegSettled() (偏航角速度稳定)
里程计保护app_zone1_flow_nav_odom_trustworthy(): 里程计数据年龄 > 500ms → abort
