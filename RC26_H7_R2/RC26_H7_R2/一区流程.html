✅ 都完成 → S2 shift_right_monitor
❌ 超时/odom失效/导航异常 → abort
② shift_right_monitor（摇摆扫描）
底盘 VW 扫掠，通过 odom_center_offset 读取物体Y坐标
VW = ±40 (sweep_dir × shift_right_slow_cmd) VY = -8 (压入补偿)
读 odom_center_offset：
▨ center_y > 1.69m → pull_back 反向扫
■ center_y 0.55~1.69m → 正常扫，超边则反方向
▪ center_y < 0.55m → pull_back 正向扫
🔴 夹爪 latch 触发: prev_state==idle 且 cur==closing/wait_close_delay → grab_monitor → clamp_wait
❌ odom 超龄(500ms) → abort
③ shift_right_clamp_wait（等夹爪）
等待夹爪控制 ClampHeadCtrl 完成闭合
超时: 10s (clamp_timeout_ms) → abort

✅ dock_ok: 夹爪到位 → 成功退出 → S4 advance_turn180
✅ upright_hold + 物体持续存在 2s: 直立夹紧 → 成功退出
❌ idle + 物体absent + 未到限位 + 电机空闲 →
🔄 retry: grab_retry_count++ → ClampHeadCtrl_Init() → 回到 S2 grab_monitor
🚫 retry ≥ 8次 → abort

▪ SKILL 第二圈 或 非SKILL → S5 forward_slow_to_limit
❌ turn命令失败/超时(15s) → abort
⑤ forward_slow_to_limit（前进撞限位）
VY = 15 缓慢前进，检测机械限位
🚚
底盘
VY=15 前进
限位检测算法:
cmd ≥ 2.0 且 4轮平均rpm ≤ 10.0 持续 180ms → 撞到限位 ✅
❌ 超时 6s (limit_timeout_ms) → abort
⑥ wait_r1_release（等R1释放）
清底盘覆盖，等待 R1 发 CC..DD 释放信号
每帧通过 R1Link_TakeSig() 检查是否有 r1_link_sig_release 信号
收到 → AppZone1_NotifyR1Release() → pending=1

R1释放后:
▪ SKILL 第一圈 (skill_lap==0) → ClampHeadCtrl_Init() + reset → 回到 S4 转180 → 重新抓取第二圈
▪ SKILL 第二圈 或 非SKILL → done
▪ R1释放前可选超时(20s, 默认禁用) → 强制退出(notify_dock_ok=0)
✓ done
active=0, done=1, failed=0
Motion_Task 检测到 IsBusy=0 + IsDone → app_flow_mode=app_flow_none
✘ abort
active=0, done=0, failed=1
导航超时/odom失效/夹爪超时/重试超限/限位超时
▶ SKILL_MODE 双圈模式 #define APP_ZONE1_SKILL_MODE 1
① 第一圈
nav(0.58,0.55)+90° → grab_monitor → clamp_wait
→ advance_turn180 → slow_limit → wait_r1_release
收到 R1 释放信号时: skill_lap==0
→ 不 done，重置 grabl 状态
→ go to advance_turn180 再做一圈
② 第二圈
(跳过nav，直接在当前位置) grab_monitor → clamp_wait
→ advance_turn180(已设 skill_lap=1, 直接进 slow_limit)
→ slow_limit → wait_r1_release
收到 R1 释放信号时: skill_lap==1
→ done
目的：第一圈夹爪抓取后先上到R1放一次，再回来抓第二次，提高容错率。 非SKILL模式(旧方案)只做一圈直接done。
▶ R1 信号接收 (USART10)
信号协议流向
r1_link_sig_releaseCC 01 CD DD (3E50)R1 → USART10 → R1Link_OnRxByte → R1Link_TakeSig → AppZone1_NotifyR1Release
// app_zone1.c - 每帧 R1 信号轮询
static void app_zone1_poll_r1_release_sig()
{
   r1_link_sig_cmd_t sig;
   if (R1Link_TakeSig(&sig) != 0 && sig == r1_link_sig_release)
     AppZone1_NotifyR1Release(); // r1_pending = 1
}
